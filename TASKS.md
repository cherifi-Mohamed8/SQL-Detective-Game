## Conventions
- Folders: lowercase (`docs/`, `pages/`)
- File names: lowercase, hyphens, English (e.g. `admin-case-new.html`)
- Shared skeleton: (header with navigation, main, footer); every page starts from it
- Branches: `page/<page-name>` (e.g. `page/cases`)
- Commit messages: imperative, e.g. "Add cases list page"
